Reading the Table

The table below illustrates how sample occupations map onto the taxonomy without requiring interaction or filtering. Each row uses concise language drawn from the coded data to show how role families, task patterns, and skills align.

Sample Occupations

Occupation Role Family Core Tasks Key Skills
Computer Programmer Software Engineering Translate system specifications into modular code; refactor services to improve reliability; document design tradeoffs for future iterations. Programming languages, version control discipline, debugging heuristics, technical writing.
Frontend Engineer Software Engineering Build accessible user interfaces from product specifications; optimize rendering performance; align interface behavior with design systems. JavaScript frameworks, accessibility guidelines, performance tuning, design system literacy.
Backend Engineer Infrastructure and Platforms Implement data services that translate business rules into reliable workflows; harden endpoints through observability and testing; tune storage and caching for throughput. Service architecture, database querying, monitoring and logging, automated testing.
DevOps Engineer Infrastructure and Platforms Automate build and release pipelines; codify infrastructure for consistent environments; monitor deployments and remediate incidents with runbooks. CI/CD orchestration, infrastructure as code, incident response, scripting.
Cloud Architect Infrastructure and Platforms Map system requirements to cloud services; design resilient network and data topologies; govern cost, security, and compliance controls. Cloud platform design, security architecture, capacity planning, cost optimization.
Cybersecurity Analyst Security and Risk Monitor systems for anomalies; investigate alerts to contain threats; advise teams on hardening practices and policy alignment. Threat detection, incident triage, vulnerability assessment, policy communication.
Database Administrator Infrastructure and Platforms Provision and tune database instances; design backup and recovery plans; enforce data integrity and access controls across applications. Query optimization, capacity management, backup strategy, access governance.
Information Technology Project Manager Program and Project Management Plan milestones and dependencies with sponsors; coordinate cross-functional teams and vendors; monitor scope, budget, and risk signals to keep delivery on track. Work breakdown planning, stakeholder facilitation, budget stewardship, change management.
Product Manager Product Strategy Translate user research into roadmap priorities; define success metrics and acceptance criteria; align engineering, design, and business partners around releases. Roadmap development, requirements elicitation, stakeholder alignment, metric definition.
Scrum Master Program and Project Management Facilitate sprint ceremonies that surface blockers; coach teams on iterative delivery; track throughput and retrospectives to refine workflow. Agile facilitation, team coaching, impediment removal, process metrics.
Business Analyst Product Strategy Elicit requirements through interviews and workflows; translate business rules into functional specifications; validate solutions against stakeholder needs. Process mapping, requirements analysis, stakeholder communication, acceptance testing.
Data Analyst Data and Analytics Clean and integrate datasets; analyze patterns that explain performance; create visual narratives that guide operational decisions. Data querying, statistical reasoning, visualization design, briefing skills.
Data Scientist Data and Analytics Frame analytical questions with stakeholders; build predictive models and evaluate their validity; deploy findings into decision tools or services. Model development, experimental design, feature engineering, stakeholder translation.
Machine Learning Engineer Software Engineering Operationalize trained models within production services; design data pipelines for training and inference; monitor drift and retrain schedules. Model serving, data pipeline design, performance optimization, monitoring.
UX Designer Design and Research Conduct user research to surface pain points; prototype flows that align with accessibility and brand; validate interfaces through usability testing. Interaction design, user research methods, prototyping tools, accessibility standards.
UX Researcher Design and Research Plan studies that explore user behaviors; synthesize qualitative and quantitative findings; communicate insights that reshape product direction. Research design, interviewing, thematic analysis, insight storytelling.
Quality Assurance Analyst Software Quality Develop test plans from requirements; execute manual and automated suites; document defects and collaborate on remediation priorities. Test case design, automation tools, defect triage, requirements traceability.
Technical Writer Knowledge and Communication Create reference and tutorial content for software releases; translate engineering concepts into audience-specific guidance; maintain documentation versioning. Information architecture, clear prose editing, audience analysis, version control.
IT Support Specialist Operations and Support Diagnose user incidents across hardware and software; apply standardized runbooks to restore service; escalate recurring issues into improvement requests. Troubleshooting, customer communication, ticket management, configuration knowledge.
Analytics Engineer Data and Analytics Model source data into reusable tables; build tests that validate data quality; publish semantic layers and dashboards for downstream analysts. Data modeling, SQL development, pipeline testing, dashboard tooling.
