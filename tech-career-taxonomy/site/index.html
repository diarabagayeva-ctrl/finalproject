Project Overview

This site documents the design of a faceted taxonomy and accompanying information architecture for a tech career orientation platform. The work draws on qualitative coding of O*NET occupational data and design research with learners, advisors, and hiring managers. The goal is to translate diffuse labor market language into a structured, navigable set of concepts.

The project foregrounds clarity and academic rigor. Each page summarizes design decisions and artifacts so that peers can trace how the taxonomy supports transparent comparisons across technology roles. All content is static and intentionally minimal to function as a clean reference for studio critiques or committee review.

Purpose of This Artifact

The website is a designed artifact that demonstrates how the taxonomy shapes the platform experience. Rather than prototype interactive features, it focuses on the conceptual scaffolding: the facets, the language choices, and example mappings to careers. This presentation allows reviewers to evaluate the logic of the classification without distractions from interface chrome.

By making the taxonomy legible in a public, static format, the project invites feedback from educators and practitioners on whether the chosen dimensions capture the breadth of contemporary tech work. It also serves as a reproducible reference for future iterations of the platform.
